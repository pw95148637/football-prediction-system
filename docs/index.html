足球預測系統

讓 LLM 在可驗證的邊界內工作。

統計模型算基準，LLM 讀新聞與陣容，程式負責算術與規則。每場的估計先鎖定，再和市場價比較，最後用賽果檢驗。實戰跑過 2026 世界盃淘汰賽，現在用於英超賽季。

Problem → Design

不把 LLM 當預言機

常見做法

  • 直接問：哪一隊會贏？
  • 要它「模擬一億次」
  • 把流暢的答案當成機率

問題

  • LLM 擅長語言，不擅長統計模擬
  • 文字合理，不代表機率可靠
  • 誰都問得到的答案，市場早已反映

所以把工作依擅長的事拆開：

可重算的 →

程式

機率、狀態、期望值、注碼、審計與測試。

非結構化理解 →

LLM

陣容、傷停、戰術、新聞脈絡。

可靠性 →

環境

資訊邊界、單向狀態、拒絕動作、事後驗證。

Evidence

驗證的結果，包括推翻自己的

RPS 是機率預測的誤差，越低越準。收盤價是開賽前最後的市場價，通常是最難贏的基準。

世界盃淘汰賽，規則事先登記

0.1621對0.1972

RPS：模型對收盤價。15 場中 11 場模型較準。

有正向訊號，但樣本太小，不構成證明。

英超 970 場，訓練範圍外

+0.0075

RPS：模型比收盤價差的幅度

差距越大，模型越常是錯的那方。系統因此把大差距當成警訊，不當成機會。
