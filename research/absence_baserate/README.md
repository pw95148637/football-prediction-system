# 英超主力先發缺陣對球隊 xG 的基準率

用途:研判或從零鑑識時,遇到查不到個人數據的缺陣球員,以同位置組的歷史基準率估計影響,不再歸零。完整數字在 `table.json`,本檔說明其來源、用法與限制。

## 樣本外檢驗

以 2014-21 擬合缺陣係數,在 2022-25(3,040 隊-場)檢驗。基準模型為「隊季 + 對手季 + 主客」,以 10 折依比賽交叉擬合,每場的預測都不使用該場本身。加入缺陣項後,逐場 xG 的均方誤差下降 0.0131(95% CI 0.0070 至 0.0191),占基準均方誤差 0.671 的 1.9%。校準斜率為 1.17 ± 0.15,表示訓練期的係數量級可以移轉到後四季。

**改善幾乎全部來自 xG-against 項**:防守項使均方誤差下降 1.7%,CI 不含 0;進攻項只降 0.26%(CI 為 −0.003 至 +0.006,不顯著),其校準斜率 0.67 ± 0.23,即訓練期高估了約三分之一,但訊號不為零。若改用前 19 輪的先發率判定主力、只在第 20–38 輪檢驗(不偷看後半季),整體改善降為 0.6%,不顯著;其中防守項仍顯著(1.0%),進攻項無改善。

## 如何使用

- 進攻乘數 = 1 + Σ Δxg_for ÷ 該隊本場基準 xG-for;防守乘數 = 1 + Σ Δxg_against ÷ 該隊本場基準 xG-against(作用在對手的期望 xG 上)。乘法版為 Π(1 + pct/100),樣本外表現與加法版相近(1.8% 對 1.9%)。
- **多人缺陣可以相加**:按同隊同場缺陣人數(1、2、3、4 人以上)設虛擬變數,xG-for 為 −0.03、−0.09、−0.17、−0.18,xG-against 為 +0.05、+0.13、+0.17、+0.29,約略呈線性;「第二人以後」的額外項為 −0.019 ± 0.027 與 +0.014 ± 0.029,不顯著。4 人以上的樣本少,xG-for 端有趨緩跡象。
- **基準的口徑**:係數是相對於「主力全部先發」。若基準由過往賽果擬合(例如 M),其中已含該隊平常的缺陣(主力平均缺席 20% 的比賽),應改用 Δ × (1 − p),p 取該球員平常的缺陣率,預設 0.2。
- 查表順序:預設用主表。已知為不可替代的先發(core)或隊內前三名的攻擊手,用分層表。4-3-3 的邊鋒在 Understat 標為 FWL/FWR,主表歸在 ST;若要依角色查,用 `by_group_alt_fwl_fwr_as_wide`(邊鋒併入 WIDE 後,WIDE −0.060 / +0.044,中鋒 ST −0.114 / +0.030)。
- **防守端的年代差異**:2022-25 每缺一名主力的 xG-against 為 +0.099,2014-21 為 +0.049,約為兩倍(z ≈ 3),樣本外防守項的校準斜率 1.7 也一致。2026-27 宜考慮使用 `by_group_recent_2022_25`(例如 CB +0.140、CM +0.124、DM +0.147,SE 約 0.035 至 0.05)。
- 例:某隊基準 xG-for 1.60、xG-against 1.10,主力 ST 與 CB 同時缺陣。進攻乘數 = 1 + (−0.083 − 0.026)/1.60 = 0.932,防守乘數 = 1 + (0.019 + 0.077)/1.10 = 1.087;若基準已含平常的缺陣,則為 0.946 與 1.070。
- CI 跨越 0 時(例如 GK、CB 的 xG-for,ST 的 xG-against),表示影響小、方向未定,不代表已證明為零。

## 資料

來源為 Understat:`getLeagueData/EPL/<季>` 提供賽程與兩隊 xG,`getMatchData/<id>` 提供名單(先發的陣型位置、分鐘、xG、xA,以及上場的替補)。共 12 季、4,560 場,全部取得,11 人先發全數齊備,無失敗請求。賽程中 Understat 自己的勝平負預測欄位在抓取時即丟棄,未使用。每場整理成 `data/matches.jsonl`(日期、主客、xG、雙方先發 11 人含位置與分組、替補上場者及分鐘)與 `data/appearances.csv`。

## 方法

- **位置分組**:GK = GK;CB = DC;FB = DR/DL/DMR/DML,另外在先發恰有 3 名 DC、且無 DR/DL/DMR/DML 時,MR/ML 為翼衛,也歸入 FB(Understat 把 3-4-3 的翼衛標成 MR/ML);DM = DMC;CM = MC;WIDE = MR/ML/AMR/AML;AM = AMC;ST = FW/FWL/FWR。
- **主力**:該隊該季先發場次 ≥ 60%(不論位置),歸入其先發次數最多的位置組。Understat 的位置隨陣型改變(4-2-3-1 的 DMC 在 4-3-3 變成 MC),若照字面要求「單一位置組 ≥ 60%」,會漏掉真正的主力:四分之一的主力只有 75% 以下的先發落在同一組。字面版本列於 `robustness.strict_key_rule`,方向與量級相同。12 季共 2,045 個主力人季,每隊每季平均 8.5 人。
- **分層**:先發率分層(core ≥ 80%、regular 60–80%)不需個人數據,看先發名單即可判斷。進攻排名分層(隊內 (xG+xA)/90 前三,且出場 ≥ 900 分鐘)則對應「隊上主要威脅」。
- **缺陣**:主力未先發的場次,包含傷停、停賽、輪換,以及加盟前或離隊後的場次。發生在該球員本季首次出場之前的缺陣占 6%,多為尚未加盟,也包含季初傷停。缺陣中 70% 完全未出場,30% 替補上場。
- **迴歸**:每隊每場一列(9,120 列),`xg_for = 隊季攻擊固定效果 + 對手季防守固定效果 + 主場 + Σ b_for[g]·己方缺陣數[g] + Σ b_against[g]·對方缺陣數[g]`。這等同於分別跑 xG-for 與 xG-against 兩條迴歸(隊季、對手季、主客、己方缺陣),並各自控制另一方的缺陣。標準誤以缺陣方的隊伍-季叢集(240 叢集);`se_twoway_*` 另以雙向叢集計算,差異很小。
- **驗證**:`selftest.py` 以模擬資料確認估計式能還原植入的效果、叢集標準誤校準正確,且效果為零時樣本外檢驗不會誤報改善。實際資料另做了敏感度檢驗:去掉每隊最後 5 輪、控制休息天數、控制雙方近 5 場 xG 狀態、只算完全未出場、字面主力定義。各係數與主表的差距均在 1.5 個 SE 內,最大者為字面主力定義下 DM 的 xG-for(−0.101 對 −0.067)。

## 限制(由重到輕)

1. **內生性未能完全排除。** 安慰劑檢驗:下一場的缺陣也能「預測」本場的 xG,也就是缺陣前的那一場已帶有部分效果。這大多集中在本場 85 分鐘前被換下的情形,即場中受傷,干擾從那一場就開始。但後衛即使踢滿 90 分鐘,下一場缺陣仍對應本場 xG-against +0.07 ± 0.02,可能是承壓時吃牌、帶傷,或被教練撤下(選擇效果)。因此防守端係數可能偏高。GK 最不可信:regular 門將的效果大於 core,符合「門將在表現差的時期被換掉」。
2. 傷停、停賽與輪換無法區分。只算完全未出場的版本最接近傷停,數字與主表相近(`did_not_play_only`)。
3. 輪換多發生在對弱隊或賽程密集時。對手季固定效果只吸收對手的平均強度;歐戰與盃賽不在資料內,休息天數只依聯賽賽程計算。
4. 勝負已定的比賽與季中換帥未建模,去掉最後 5 輪、控制近期狀態後,係數變動均在 1.1 個 SE 內。
5. 主力身分使用整季資訊(偷看未來)。不偷看的版本在進攻端沒有樣本外改善。
6. 係數是教練換人後的淨效果,替補的品質未建模。xG 為單場雜訊極大的量(殘差標準差 0.71),單一球員的效果只占一小部分。
